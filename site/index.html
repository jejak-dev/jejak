Jejak

A local-first workbench for coding agents, with cross-repo memory.

Install on macOS

curl -fsSL https://raw.githubusercontent.com/jejak-dev/jejak/main/install.sh | sh

Installs Jejak.app into ~/Applications. No sudo, no data is touched.
